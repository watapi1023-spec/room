# 購入履歴から商品候補を出す

楽天・Amazonの購入履歴CSVをここに置くと、`scripts/analyze_purchase_history.py` が
リピート購入・購入金額などを集計し、「今月の商品候補」のベースとなる一覧を作成します。

## ファイルの置き方
- ファイル名は **`rakuten_`** または **`amazon_`** で始める（大文字小文字どちらでもよい）。
  例: `rakuten_202610.csv`, `amazon_202610.csv`
  （このプレフィックスで集計元を判定するため、必ず付けてください）
- 複数月分を並べて置いてもOK（まとめて集計されます）。

## CSVの取得方法（概要）
- **楽天**: 「購入履歴」ページからCSVダウンロード、またはページ内容をCSV化。
- **Amazon**: アカウント設定 →「注文履歴レポートをリクエスト」でCSVをダウンロード
  （生成まで時間がかかる場合あり）。

## 必要な列（ヘッダー名は多少違っていても自動認識します）
| 項目 | 認識するヘッダー名の例 |
|---|---|
| 購入日 | 注文日 / 購入日 / 注文日時 / Order Date |
| 商品名 | 商品名 / タイトル / 品名 / Title |
| 金額 | 小計 / 商品小計 / 単価 / 価格 / 合計 / Item Total / Item Subtotal |
| 数量 | 数量 / 個数 / Quantity（無ければ1件として扱う） |

上記のどれにも当てはまらないヘッダーの場合、スクリプトが「どの列か分からない」と
エラーを出して該当ファイルをスキップします（推測で処理しない方針）。その場合は
`scripts/analyze_purchase_history.py` 冒頭の `HEADER_ALIASES` にヘッダー名を追加してください。

## 注意（プライバシー）
購入履歴には家計・個人情報が含まれるため、**生のCSVファイルはGit管理対象外**にしています
（`.gitignore` 参照）。このフォルダに置いたままでも集計・分析には使えますが、
リポジトリには取り込まれません。集計結果（商品名・金額の要約のみ）は `output/` に出力され、
そちらはGit管理されます。
