# 楽天ROOM × SNSアフィリエイト 運用プロジェクト (room)

## 📌 目的
楽天ROOMの商品紹介・更新を仕組み化し、Instagram／X（旧Twitter）と連携させて
アフィリエイト運用を効率よく回すことを目的とします。

**今回のスコープ（下書き作成の自動化）**：
Claudeが担当するのは「商品紹介文の下書き作成」と「投稿状況の管理」までです。
楽天ROOM・Instagram・Xへの実際の投稿はご本人が手動で行います
（各SNSの公式投稿API連携やアカウント自動操作は行いません）。

## ⚙️ 運用体制
| 媒体 | 位置づけ | 状態 |
|---|---|---|
| 楽天ROOM | アフィリエイトのハブ（商品リンク集約） | 既存 |
| X（旧Twitter） | 既存の「ママアカウント」を活用 | 既存アカウントで運用 |
| Instagram | ママ向け新規アカウント | 開設はご本人が実施（`設計書.md` にチェックリストあり） |

## 📂 フォルダ構成
* `input/products/` : 紹介したい商品の情報をここに置く（1商品1ファイル）。書き方は `input/products/README.md` 参照。
* `output/drafts/` : Claudeが作成した下書き（楽天ROOM紹介文・Instagramキャプション・X投稿文）。
* `output/posting_log.xlsx` : 投稿管理ログ（`scripts/update_posting_log.py` が自動生成・更新）。
* `scripts/` : 機械的な集計処理のプログラム。

## 🔁 使い方（基本フロー）
1. `input/products/` に商品情報ファイルを追加する（`input/products/_template.md` をコピーして使う）。
2. このリポジトリのセッションで「商品の下書きを作って」と依頼する。
   * Claudeが商品情報を読み、**楽天ROOM紹介文・Instagramキャプション（ハッシュタグ付き）・X投稿文**の下書きを
     `output/drafts/<商品スラッグ>_YYYYMMDD.md` に作成する（フロントマターに投稿済みフラグを持たせる）。
   * アフィリエイト表記（#PR 等）は法令上必須のため、**下書きに必ず含める**（詳細は `設計書.md` の「表示義務」参照）。
3. 下書き内容を確認・調整し、各SNSへ**手動で投稿**する。
4. 投稿が済んだら、該当ファイルのフロントマターの `rakuten_room_posted` / `instagram_posted` / `x_posted` を
   `true` に書き換える。
5. `python3 scripts/update_posting_log.py` を実行すると、`output/drafts/` 内の全下書きの状態を集計して
   `output/posting_log.xlsx` を更新する（どの商品がどの媒体に投稿済みか一覧で確認できる）。

## 🤖 Claudeへの指示ルール（プロンプトの前提）
* 生成する文章は「ママ」ペルソナに合う、親しみやすいトーンにしてください。
* アフィリエイト・PR表記（ステマ規制対応）を必ず本文中に明記してください。省略しないでください。
* 個人が特定されうる情報（子どもの氏名・通う施設・自宅周辺の写真など）は下書きに含めないでください。
* 詳しい設計・運用ルールは `設計書.md` を参照してください。
