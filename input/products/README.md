# 商品情報の入力フォーマット

`_template.md` をコピーして、商品ごとに1ファイルを作成してください
（ファイル名は自由。例: `2026-08-12_ベビーカー.md`）。

## 記入項目
- **商品名**: 正式名称
- **商品URL**: 楽天市場の商品ページURL（アフィリエイトリンク化前のURLでよい）
- **価格**: 参考価格
- **カテゴリ**: 例）育児グッズ／時短家電／コスメ 等
- **おすすめポイント**: 箇条書きで3〜5個（実際に使った感想があれば具体的に）
- **ターゲット**: どんな読者に届けたいか（例：0歳児のママ、共働き家庭 等）
- **備考**: 使用歴・注意点・PR案件かどうか（提供品の場合は必ず記載）

この情報をもとに、Claudeが `output/drafts/` に楽天ROOM・Instagram・Xの下書きを作成します。
